# 文档状态说明

本目录用于保存 Bandi 的产品背景、阶段性方案、技术说明和历史参考，不代表其中所有内容均为当前实现契约。

## 使用原则

- 当前明确的产品与界面要求，以及根目录 `CLAUDE.md` 中的产品和安全边界优先。
- 实现功能前，以现有代码、实际界面和相关测试确认真实状态。
- 产品说明、页面架构、线框图和阶段性方案默认仅作背景参考；发现与当前要求或实现冲突时，不应据此恢复旧设计。
- 接口、安全、数据和工具能力相关文档应在涉及对应改动时按需查阅，并结合代码与测试核验。
- 已完全失效且可能误导实现的文档可移入 `archive/`；归档前应先提炼仍然有效的约束。
- `archive/` 中的内容仅用于追溯历史，除非明确要求，否则不再维护。
