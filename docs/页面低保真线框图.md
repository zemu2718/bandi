# 班底页面低保真线框图

> 文档版本：v3.0
> 更新日期：2026-09-08
> 状态：Team-scoped Shell 当前有效线框契约
> 关联文档：[《产品与页面架构》](./产品与页面架构.md) · [《技术架构》](./技术架构.md)

## 1. 线框目标与边界

本文描述 Bandi Desktop 当前页面结构、默认信息密度、关键交互和响应式降级。默认主线只有：

```text
Team → Agent → 可选的 Team-scoped TaskBrief
```

线框不引入任务执行、聊天、内嵌终端、人员调度、审批、Todo、日志、监控、汇报、验收或 Session 状态。TaskBrief 只是一份 Team-scoped 轻量简报。

Bandi 只处理 Bandi 自有数据，不接受、访问、扫描、修改或删除任意用户目录。所有页面、空态、确认和结果文案都必须遵守此边界。

## 2. 页面地图

```text
全局 Shell
├── 任务简报                     /tasks
├── Agent                        /agents
│   ├── 创建 / 导入              /agents/new
│   └── Agent 详情               /agents/:agentId
├── 资产                         /assets
└── 设置                         /settings

系统路由
└── 配置状态 / 首次欢迎 / 恢复    /
```

一级菜单固定为“任务简报 / Agent / 资产”，设置固定在底部。Team 菜单提供切换、编辑当前 Team 和新建 Team。配置状态保留为系统落点，不占用一级菜单；存在待处理项时从顶栏进入。正常且已有 Agent 时，冷启动直接进入 Agent 列表。一级菜单与 Agent 二级栏分别收展。

## 3. S-00 全局 Shell

### Desktop

```text
┌──────────────────┬──────────────────┬──────────────────────────┐
│ [独] 独立工作室⌄  │ 当前 Team Agent   │ 页面标题                  │
│ 任务简报          │ [头像] Agent A    │ 说明          主操作      │
│ Agent             │ [头像] Agent B    ├──────────────────────────┤
│ 资产              │                  │ 页面内容                  │
│                   │ [收起 Agent 栏]   │                           │
│ 设置              │                  │                           │
│ 切换到深色        │                  │                           │
│ [收起侧栏]        │                  │                           │
└──────────────────┴──────────────────┴──────────────────────────┘
```

规则：

- 左上入口直接表达当前 Team；一级菜单收起时只显示 1–2 字符 Team 标识；
- Team 菜单用于切换 Team、编辑当前 Team 和新建 Team；
- 一级菜单宽屏默认展开、窄屏默认收起；
- Agent 二级栏只显示当前 Team 的 Agent；
- 最近访问仅用于当前 Team 内排序，不表达在线、运行、Session 或未读；
- 一级菜单与 Agent 二级栏各自提供收展入口，互不改变对方状态；
- 设置不属于 Team 次级对象；
- 页面 body 不横向滚动。

### Team 切换器

```text
┌────────────────────────┐
│ 个人班底          当前  │
│ 独立工作室              │
├────────────────────────┤
│ 编辑当前 Team           │
│ 新建 Team               │
└────────────────────────┘
```

交互：

- Enter/Space 打开，方向键选择，Enter 确认，Escape 关闭；
- 关闭后焦点回到触发按钮；
- 切换 Team 后进入 `/agents`；
- 清理不属于新 Team 的 Agent 和 TaskBrief 选择；
- 单 Team 时仍保留当前 Team 与次级入口；
- 空数据时 Personal Team 作为确定性回退。

- Agent 默认归属当前 Team；首次通常是 Personal Team；

- 不展示产品导览轮播或执行能力宣传；

```text
┌──────────────────────────────────────────────────┐
```

### 导入 Agent

当前支持用户通过系统文件选择器明确选择单个 Claude Code Agent 文件：

```text
选择单个 .claude/agents/*.md
→ 预览名称、描述、Instructions 与忽略字段
→ 独立确认创建受管副本
```

- 文件选择器只返回受支持的单文件，不接受目录或手输路径；
- 来源变化时拒绝提交并要求重新预览；
- 原文件永不修改；
- 未识别 frontmatter 不自动变成权限、Rules、Skills、MCP 或 Memory；
- Bandi 不自动发现或扫描其他文件。

## 8. A-04 配置编辑与保存

```text
┌──────────────────────────────────────────────────┐
│ 编辑 Instructions                                │
│                                                  │
│ [完整可编辑内容                                ] │
│                                                  │
│ 当前基线：已载入                                  │
│ [取消]                              [保存更改]    │
└──────────────────────────────────────────────────┘
```

| 状态 | UI |
| --- | --- |
| 已保存 | 使用服务 canonical 结果更新并退出编辑 |
| 无变化 | 退出编辑，不显示新版本 |
| 外部变化 | 保留 draft，展示 base/current/proposed |
| 需要确认 | 展示真实权限影响，确认后重试 |
| 格式错误 | 错误紧邻字段或文件位置，保留输入 |
| 保存失败 | 说明 Bandi 自有数据状态与恢复入口，保留 draft |

不提供“强制覆盖”。

## 9. C-01 条件 Dialog

### 外部变化

```text
配置已在外部修改

开始编辑时     当前版本       你的修改
[base]         [current]      [proposed]

[放弃我的修改] [复制我的修改] [基于当前内容重新编辑]
```

### 扩大长期权限

```text
确认扩大长期权限

当前边界：读取指定配置
新边界：使用更多工具能力

这会改变 Agent 的长期默认能力，不会批准当前 Session 的工具调用。

[取消] [确认更改]
```

### 永久删除 Agent

```text
永久删除 Agent

将删除：该 Agent 的 Bandi 受管配置、Agent 长期 Memory 和版本记录
不会处理：任意用户目录或其中的文件

输入服务提供的确认文本
[取消] [永久删除 Agent]
```

- 先展示共享引用、长期 Memory、Revision 和 Backup 影响；
- 有 blocker 时只展示解除建议；
- 无 blocker 时才显示精确确认文本；
- 预览过期或目标变化时清空旧确认；
- 所有 Dialog 支持 Escape、可见焦点与关闭后的焦点恢复。

## 13. E-01 在 Claude Code 中继续

Client Launch v3 只准备上下文，不打开目录、终端或进程。

### 默认状态

```text
┌──────────────────────────────────────────────────┐
│ 在 Claude Code 中继续                             │
├──────────────────────────────────────────────────┤
│ Team        独立工作室                            │
│ Agent       研究助手                              │
│ 任务简报    不选择                                │
│                                                  │

```

规则：

- Team 与 Agent 必填，TaskBrief 可跳过；
- 切 Team 清空 Agent 和 TaskBrief 选择；

- 请求只包含稳定 ID，不包含路径、cwd、prompt、正文、命令、argv、环境变量或脚本；
- 结果只表达“上下文已准备”“请求被拒绝”“尚未尝试”；
- 不打开终端或文件管理器，不启动 Claude Code，不跟踪 PID、输出或 Session；
- “上下文已准备”不等于 Claude Code 或任务已启动。

## 15. 统一状态与文案

### 配置状态

- 已保存
- 无变化
- 外部已修改
- 需要确认
- 格式需要调整
- 保存失败
- 版本记录待恢复

### 上下文状态

- 上下文已准备
- 请求被拒绝
- 尚未尝试

不得出现“已请求打开目录”“Session 已启动”“Agent 正在运行”“任务执行中”等 Bandi 无法证明或不再执行的状态。

### 安全文案

删除、恢复和数据边界统一使用：

> 仅处理 Bandi 自有数据。Bandi 不接受、访问、扫描、修改或删除任意用户目录。

## 18. 已确认决策

1. Team → Agent → 可选 Team-scoped TaskBrief 是唯一产品主线。
2. Personal Team 始终存在且不可删除。
3. 每个 Agent 必须且只能属于一个 Team。
4. 每个 TaskBrief 必须且只能属于一个 Team，不持久化 Agent。
5. 一级菜单为任务简报、Agent、资产，设置固定在底部。
6. Memory 仅为 Agent 长期，直接通过安全保存链写入并生成 Revision。
7. Client Launch v3 是 context-only 合同。
8. Desktop 不执行 AI 编程工具，不管理 Session。
9. 删除与恢复只处理 Bandi 自有数据。
10. Bandi 不接受、访问、扫描、修改或删除任意用户目录。
11. 旧非零开发数据直接重置，不建设迁移或运行时兼容层。

## 19. 验收重点

- Team 切换器键盘、Escape 和焦点恢复；
- 当前 Team Agent 与 TaskBrief 隔离；
- 一级菜单与 Agent 二级栏独立收展；
- TaskBrief 无 Agent 和执行状态；
- Agent 长期 Memory 直接保存、外部变化保护与 Revision；
- Client Launch v3 请求与结果不含路径、命令或正文；
- 删除与恢复文案明确只处理 Bandi 自有数据；
- Dialog 键盘行为、亮暗主题和窄屏；
- body 无横向溢出；
- 页面 console 无错误。
